# Final Submission Checklist

## LMS Requirements

- [ ] AI acknowledgement completed.
- [ ] Presentation slot booked.
- [ ] One zip file only.
- [ ] Zip is under 250 MB.
- [ ] Both students submit if required.
- [ ] GitHub repository link included.

## Code

- [ ] Source code included.
- [ ] `node_modules` excluded.
- [ ] `.env` secrets excluded.
- [ ] `.env.example` included.
- [ ] README included.
- [ ] APK/build included or build instructions included.

## Evidence

- [ ] Screenshots of app functionality.
- [ ] Screenshots/videos of testing results.
- [ ] Jest result screenshots, at least 3 each if required by marker.
- [ ] Firebase Test Lab screenshots/logs, different device per person if possible.
- [ ] GitHub commits and branches from both contributors.
- [ ] Sprint boards, user stories, and testing tasks.
- [ ] Team communication evidence.
- [ ] Backup demo video.

## Documents

- [ ] User manual.
- [ ] Testing and deployment report.
- [ ] Presentation script or demo notes.
- [ ] Firebase Test Lab evidence notes.
- [ ] AI acknowledgement draft retained for your own reference.

## Presentation

- [ ] 3-minute app demo rehearsed.
- [ ] 1-minute testing/Git evidence rehearsed.
- [ ] 1-minute code explanation rehearsed.
- [ ] Both members can answer architecture, testing, Firebase, SQLite, sensor/GPS, background task, and notification questions.
- [ ] Student card/photo ID ready.
